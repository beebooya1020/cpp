```cpp
class Triangle {
public:
    int x, y, area;
    double getArea();
};
```
- Triangle 클래스 선언
- x, y : 밑변과 높이
- area : 선언되어 있지만 실제로 사용되지 않음
- getArea() : 삼각형의 넓이 계산 함수

```cpp
double Triangle::getArea() {
    return x * y / 2;
}
```
- 삼각형 넓이 계산
- 공식: (밑변 × 높이) / 2
