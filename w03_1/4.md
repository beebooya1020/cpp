```cpp
using namespace std;
```
- std 네임스페이스 사용

```cpp
class Rectangle {
public:
    int x, y;
    int width;
    int height;

    int getArea();
    int length();
    void getRightBottom();
};
```
- Rectangle 클래스 선언
- x, y : 좌측상단 좌표
- width, height : 가로와 세로 길이
- getArea() : 면적 계산 함수
- length() : 둘레 계산 함수
- getRightBottom() : 우측하단 좌표 출력 함수

```cpp
int Rectangle::getArea() {
    return width * height;
}
```
- 사각형의 면적 계산
- 공식: 가로 × 세로

```cpp
int Rectangle::length() {
    return 2 * (width + height);
}
```
- 사각형의 둘레 계산
- 공식: 2 × (가로 + 세로)

```cpp
void Rectangle::getRightBottom() {
    int rightX = x + width;
    int rightY = y - height;
    cout << "사각형의 우측하단의 좌표는 (" << rightX << ", " << rightY << ")" << endl;
}
```
- 우측하단 좌표 계산 및 출력
- x + width, y - height 사용
