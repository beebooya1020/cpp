```cpp
class Sphere {
public:
    int r, area , vol;
    double getArea();
    double getVol();
};
```
- Sphere 클래스 선언
- r : 반지름
- area, vol : 선언되어 있지만 실제 계산에는 사용되지 않음
- getArea() : 구의 겉넓이 계산 함수
- getVol() : 구의 부피 계산 함수

```cpp
double Sphere::getArea() {
    return 4*r*r*PI;
}
```
- 구의 겉넓이 계산
- 공식: 4πr²

```cpp
double Sphere::getVol(){
    return r*r*r*(4.0/3.0)*PI;
}
```
- 구의 부피 계산
- 공식: (4/3)πr³
